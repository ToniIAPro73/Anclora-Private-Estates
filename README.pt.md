## O que é

Anclora Private Estates é a marca imobiliária de luxo ultra premium do ecossistema Anclora, centrada em Maiorca. Apresenta propriedades exclusivas com uma identidade visual dourado/azul-marinho e tipografia editorial (Cardo + Inter + Fraunces).

## Categoria no ecossistema

| Campo | Valor |
|---|---|
| Categoria | Ultra Premium |
| Destaque da marca | `#D4AF37` |
| Tipografia | Cardo + Inter + Fraunces |
| Repositório canônico | `anclora-private-estates` |

## Funcionalidades principais

- Apresentação editorial de propriedades de luxo
- Animações de scroll e interação (GSAP)
- Sistema de componentes acessível (Radix UI)
- Formulários validados (React Hook Form + Zod)
- Suporte multi-idioma (11 idiomas em produção)

## Stack tecnológico

| Área | Tecnologia |
|---|---|
| Framework | Vite, React, TypeScript |
| Animação | GSAP |
| UI | Radix UI |
| Formulários | React Hook Form, Zod |
| Tipografia | Cardo, Inter, Fraunces |

## Início local

```bash
npm install
npm run dev
```

## Idiomas suportados

O produto em produção suporta 11 idiomas: Español (padrão), Català, Deutsch, English, Svenska, Français, Italiano, Dansk, Nederlands, Norsk, Português (`ULTRA_PREMIUM_LOCALES`, `src/lib/ancloraLanguageToggle.ts`). Esta documentação é mantida nos 11 idiomas do produto.
