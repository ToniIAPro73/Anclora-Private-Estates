## Hvad det er

Anclora Private Estates er Anclora-økosystemets ultra premium-mærke for luksusejendomme med base på Mallorca. Præsenterer eksklusive ejendomme med en guld/marineblå visuel identitet og redaktionel typografi (Cardo + Inter + Fraunces).

## Nøglefunktioner

- Redaktionel præsentation af luksusejendomme
- Scroll- og interaktionsanimationer (GSAP)
- Tilgængeligt komponentsystem (Radix UI)
- Validerede formularer (React Hook Form + Zod)
- Flersproget support (11 sprog i produktion)

## Teknologistak

| Område | Teknologi |
