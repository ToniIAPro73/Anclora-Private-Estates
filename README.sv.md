## Vad det är

Anclora Private Estates är Anclora-ekosystemets ultra premium-varumärke för lyxfastigheter, centrerat på Mallorca. Presenterar exklusiva fastigheter med en guld/marinblå visuell identitet och redaktionell typografi (Cardo + Inter + Fraunces).

## Huvudfunktioner

- Redaktionell presentation av lyxfastigheter
- Scroll- och interaktionsanimationer (GSAP)
- Tillgängligt komponentsystem (Radix UI)
- Validerade formulär (React Hook Form + Zod)
- Flerspråkigt stöd (11 språk i produktion)

## Teknikstack

| Område | Teknik |
|---|---|
| Framework | Vite, React, TypeScript |
| Animation | GSAP |
| UI | Radix UI |
| Formulär | React Hook Form, Zod |
| Typografi | Cardo, Inter, Fraunces |

## Lokal start

```bash
npm install
npm run dev
```

## Språk som stöds

Produktionsprodukten stöder 11 språk: Español (standard), Català, Deutsch, English, Svenska, Français, Italiano, Dansk, Nederlands, Norsk, Português (`ULTRA_PREMIUM_LOCALES`, `src/lib/ancloraLanguageToggle.ts`). Denna dokumentation underhålls på alla 11 produktspråk.
