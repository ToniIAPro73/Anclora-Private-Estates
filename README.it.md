## Cos'è

Anclora Private Estates è il marchio immobiliare di lusso ultra premium dell'ecosistema Anclora, con sede a Maiorca. Presenta proprietà esclusive con un'identità visiva oro/blu navy e tipografia editoriale (Cardo + Inter + Fraunces).

## Categoria nell'ecosistema

| Campo | Valore |
|---|---|
| Categoria | Ultra Premium |
| Accento del marchio | `#D4AF37` |
| Tipografia | Cardo + Inter + Fraunces |
| Repository canonico | `anclora-private-estates` |

## Funzionalità principali

- Presentazione editoriale di proprietà di lusso
- Animazioni di scroll e interazione (GSAP)
- Sistema di componenti accessibile (Radix UI)
- Moduli validati (React Hook Form + Zod)
- Supporto multilingue (11 lingue in produzione)

## Stack tecnologico

| Area | Tecnologia |
|---|---|
| Framework | Vite, React, TypeScript |
| Animazione | GSAP |
| UI | Radix UI |
| Moduli | React Hook Form, Zod |
| Tipografia | Cardo, Inter, Fraunces |

## Avvio locale

```bash
npm install
npm run dev
```

## Lingue supportate

Il prodotto in produzione supporta 11 lingue: Español (predefinita), Català, Deutsch, English, Svenska, Français, Italiano, Dansk, Nederlands, Norsk, Português (`ULTRA_PREMIUM_LOCALES`, `src/lib/ancloraLanguageToggle.ts`). Questa documentazione è mantenuta in tutte le 11 lingue del prodotto.
