## Wat het is

Anclora Private Estates is het ultra premium luxevastgoedmerk van het Anclora-ecosysteem, gevestigd op Mallorca. Presenteert exclusieve eigendommen met een goud/marineblauwe visuele identiteit en redactionele typografie (Cardo + Inter + Fraunces).

## Belangrijkste functies

- Redactionele presentatie van luxe eigendommen
- Scroll- en interactieanimaties (GSAP)
- Toegankelijk componentsysteem (Radix UI)
- Gevalideerde formulieren (React Hook Form + Zod)
- Meertalige ondersteuning (11 talen in productie)
