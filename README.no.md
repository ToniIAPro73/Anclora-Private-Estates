## Hva det er

Anclora Private Estates er Anclora-økosystemets ultra premium-merke for luksuseiendommer, med base på Mallorca. Presenterer eksklusive eiendommer med en gull/marineblå visuell identitet og redaksjonell typografi (Cardo + Inter + Fraunces).

## Nøkkelfunksjoner

- Redaksjonell presentasjon av luksuseiendommer
- Scroll- og interaksjonsanimasjoner (GSAP)
- Tilgjengelig komponentsystem (Radix UI)
- Validerte skjemaer (React Hook Form + Zod)
- Flerspråklig støtte (11 språk i produksjon)

## Lokal oppstart

```bash
npm install
npm run dev
```

## Støttede språk

Produksjonsproduktet støtter 11 språk: Español (standard), Català, Deutsch, English, Svenska, Français, Italiano, Dansk, Nederlands, Norsk, Português (`ULTRA_PREMIUM_LOCALES`, `src/lib/ancloraLanguageToggle.ts`). Denne dokumentasjonen vedlikeholdes på alle 11 produktspråk.
