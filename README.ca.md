## Què és

Anclora Private Estates és la marca ultra premium de béns immobles de luxe de l'ecosistema Anclora, centrada a Mallorca. Presenta propietats exclusives amb una identitat visual or/blau marí i tipografia editorial (Cardo + Inter + Fraunces).

## Categoria a l'ecosistema

| Camp | Valor |
|---|---|
| Categoria | Ultra Premium |
| Accent de marca | `#D4AF37` |
| Tipografia | Cardo + Inter + Fraunces |
| Repositori canònic | `anclora-private-estates` |

## Funcionalitats principals

- Presentació editorial de propietats de luxe
- Animacions de scroll i interacció (GSAP)
- Sistema de components accessible (Radix UI)
- Formularis validats (React Hook Form + Zod)
- Suport multi-idioma (11 idiomes en producció)

## Stack tecnològic

| Àrea | Tecnologia |
|---|---|
| Framework | Vite, React, TypeScript |
| Animació | GSAP |
| UI | Radix UI |
| Formularis | React Hook Form, Zod |
| Tipografia | Cardo, Inter, Fraunces |

## Inici local

```bash
npm install
npm run dev
```

## Idiomes suportats

El producte en producció admet 11 idiomes: Español (predeterminat), Català, Deutsch, English, Svenska, Français, Italiano, Dansk, Nederlands, Norsk, Português (`ULTRA_PREMIUM_LOCALES`, `src/lib/ancloraLanguageToggle.ts`). Aquesta documentació es manté en els 11 idiomes del producte.
