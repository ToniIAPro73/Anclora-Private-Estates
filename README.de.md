## Was es ist

Anclora Private Estates ist die Ultra-Premium-Luxusimmobilienmarke des Anclora-Ökosystems mit Schwerpunkt Mallorca. Sie präsentiert exklusive Objekte mit einer Gold/Marineblau-Bildsprache und editorieller Typografie (Cardo + Inter + Fraunces).

## Kategorie im Ökosystem

| Feld | Wert |
|---|---|
| Kategorie | Ultra Premium |
| Markenakzent | `#D4AF37` |
| Typografie | Cardo + Inter + Fraunces |
| Kanonisches Repository | `anclora-private-estates` |

## Kernfunktionen

- Editorielle Präsentation von Luxusimmobilien
- Scroll- und Interaktionsanimationen (GSAP)
- Barrierefreies Komponentensystem (Radix UI)
- Validierte Formulare (React Hook Form + Zod)
- Mehrsprachige Unterstützung (11 Sprachen in Produktion)

## Technologie-Stack

| Bereich | Technologie |
|---|---|
| Framework | Vite, React, TypeScript |
| Animation | GSAP |
| UI | Radix UI |
| Formulare | React Hook Form, Zod |
| Typografie | Cardo, Inter, Fraunces |

## Lokaler Start

```bash
npm install
npm run dev
```

## Unterstützte Sprachen

Das Produkt unterstützt in der Produktion 11 Sprachen: Español (Standard), Català, Deutsch, English, Svenska, Français, Italiano, Dansk, Nederlands, Norsk, Português (`ULTRA_PREMIUM_LOCALES`, `src/lib/ancloraLanguageToggle.ts`).

Diese Dokumentation wird in ES/EN/DE gepflegt.
